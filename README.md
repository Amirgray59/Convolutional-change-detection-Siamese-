# Convolutional Change Detection with Siamese Networks

**convolutional neural network (CNN)** architectures for 
**change detection in satellite imagery**, with **Siamese framework**. The models take two images from different time lines and predict the changes areas.

## Features

- **Siamese U-Net (Concatenation)**.  
- **Siamese U-Net (Difference)**   
- **U-Net** – baseline convolutional segmentation model.  
- **FresUNet** – U-Net.  
- **Training on OSCD Dataset** .  
- **Pretrained checkpoint** – (`net-best_epoch-24_fm-0.5993578927722405.pth.tar`).
